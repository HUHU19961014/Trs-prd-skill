# 实用工具集

## 值列表5要素检查表

| 要素 | 检查项 | 状态 |
|------|--------|------|
| 取数来源 | 取哪个表/快码？ | ☐ |
| 级联关系 | 选A后B取什么？ | ☐ |
| 默认规则 | 单值是否默认带出？ | ☐ |
| 展示要求 | 显示名称还是值？ | ☐ |
| 支持搜索 | 需要模糊搜索？ | ☐ |

## 校验规则3要素检查表

| 要素 | 检查项 | 状态 |
|------|--------|------|
| 时机 | 保存时/实时/关闭时 | ☐ |
| 条件 | XX字段不允许为空 | ☐ |
| 报错 | "[XX]不能为空，请填写后保存" | ☐ |

## 最小输入集检查表（Step 0.5）

| 类别 | 检查项 | 状态 |
|------|--------|------|
| 粒度 | 批次/箱/件/序列号（至少1） | ☐ |
| 链路 | 关键节点（>=2） | ☐ |
| 扫码 | 点位与频率（>=1例） | ☐ |
| 编码 | 码制/条码规则 | ☐ |
| 集成 | ERP/MES/WMS/QMS/PLM（或明确"不适用"） | ☐ |
| 审计 | 留痕/更正机制（需要/不需要/待确认） | ☐ |

## 输出门禁检查表

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 章节完整性 | 1-8章必须出现 | ☐ |
| 非功能需求 | 第7章必须出现（简版可） | ☐ |
| 发布计划 | 第8章必须出现（简版可） | ☐ |
| 复杂度 | 第10或11章至少其一 | ☐ |
| 验收标准 | 每子功能>=3条 | ☐ |
| 追溯验收 | 可演练、可导出、可审计 | ☐ |
| 报错信息 | 字段级，无模糊词 | ☐ |

## 报错信息质量检查

**❌ 错误示例：**
- "操作失败"
- "请检查输入"
- "数据错误"
- "系统异常"

**✅ 正确示例：**
- "[文件名称]不能为空，请填写后保存"
- "[编码]已存在，请重新命名"
- "[手机号]格式错误，请输入11位数字"
- "[数量]必须大于0"
