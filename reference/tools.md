# 实用工具集

## 值列表5要素检查表

| 要素 | 检查项 | 状态 |
|------|--------|------|
| 取数来源 | 取哪个表/快码？ | ☐ |
| 级联关系 | 选A后B取什么？ | ☐ |
| 默认规则 | 单值是否默认带出？ | ☐ |
| 展示要求 | 显示名称还是值？ | ☐ |
| 支持搜索 | 需要模糊搜索？ | ☐ |

## 校验规则3要素检查表

| 要素 | 检查项 | 状态 |
|------|--------|------|
| 时机 | 保存时/实时/关闭时 | ☐ |
| 条件 | XX字段不允许为空 | ☐ |
| 报错 | "[XX]不能为空，请填写后保存" | ☐ |

## 最小输入集检查表（Step 0.5）

| 类别 | 检查项 | 状态 |
|------|--------|------|
| 粒度 | 批次/箱/件/序列号（至少1） | ☐ |
| 链路 | 关键节点（>=2） | ☐ |
| 扫码 | 点位与频率（>=1例） | ☐ |
| 编码 | 码制/条码规则 | ☐ |
| 集成 | ERP/MES/WMS/QMS/PLM（或明确"不适用"） | ☐ |
| 审计 | 留痕/更正机制（需要/不需要/待确认） | ☐ |

## 输出门禁检查表

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 章节完整性 | 1-8章必须出现 | ☐ |
| 非功能需求 | 第7章必须出现（简版可） | ☐ |
| 发布计划 | 第8章必须出现（简版可） | ☐ |
| 复杂度 | 第10或11章至少其一 | ☐ |
| 验收标准 | 每子功能>=3条 | ☐ |
| 追溯验收 | 可演练、可导出、可审计 | ☐ |
| 报错信息 | 字段级，无模糊词 | ☐ |

## 报错信息质量检查

**❌ 错误示例：**
- "操作失败"
- "请检查输入"
- "数据错误"
- "系统异常"

**✅ 正确示例：**
- "[文件名称]不能为空，请填写后保存"
- "[编码]已存在，请重新命名"
- "[手机号]格式错误，请输入11位数字"
- "[数量]必须大于0"

## 补充逻辑检查清单

### 查询逻辑
- [ ] 查询条件是否必填？空条件时展示什么数据？
- [ ] 查询结果默认排序规则？
- [ ] 哪些字段支持模糊查询？
- [ ] 是否支持高级查询/组合查询？

### 删除校验逻辑
- [ ] 删除前是否需要检查被引用情况？
- [ ] 被引用时的报错信息是什么？
- [ ] 是否支持级联删除？还是禁止删除？
- [ ] 删除确认弹窗的提示语？

### 自动编号逻辑
- [ ] 编码生成规则是什么？
- [ ] 流水号从多少开始？位数固定吗？
- [ ] 失效/删除后编码是否释放？
- [ ] 是否有特殊编码前缀规则？

### 验重逻辑
- [ ] 哪些字段/字段组合需要验重？
- [ ] 验重时机：保存时/实时？
- [ ] 重复时的报错信息是什么？

### 失效逻辑（级联处理）
- [ ] 失效是否影响子级数据？
- [ ] 失效后数据是否可恢复？
- [ ] 失效数据在查询中是否可见？
- [ ] 失效数据是否允许新增关联？

### 权限控制
- [ ] 功能权限：哪些角色可以操作？
- [ ] 数据权限：用户可以看到哪些范围的数据？
- [ ] 操作权限：新增/编辑/删除/导出权限是否分开控制？

### 数据一致性
- [ ] 是否存在跨表事务？
- [ ] 异常时如何回滚？
- [ ] 是否有数据补偿机制？

## 业务背景四段式检查清单

### 第一段：业务场景
- [ ] 描述具体的业务流程
- [ ] 说明用户在什么情况下使用这个功能
- [ ] 涉及哪些业务环节？

### 第二段：行业特点
- [ ] 本行业有什么特殊要求？
- [ ] 本企业有什么特殊之处？
- [ ] 涉及哪些专业领域术语？

### 第三段：当前痛点
- [ ] 没有这个功能时用户怎么做的？
- [ ] 存在什么困难或问题？
- [ ] 有什么数据支撑（错误率、处理时间等）？

### 第四段：解决方向
- [ ] 本功能如何解决这些问题？
- [ ] 预期达到什么效果？
- [ ] 成功指标是什么？

## 功能依赖图绘制指南

### 图中应包含
- [ ] 本功能模块
- [ ] 上游依赖（本功能依赖哪些功能提供数据）
- [ ] 下游依赖（哪些功能依赖本功能提供数据）
- [ ] 数据流向标注

### 常用符号
- 矩形：功能模块
- 箭头：数据流向
- 虚线箭头：可选/弱依赖
- 颜色区分：核心功能/辅助功能

### 示例
```
[文件类型配置] ──→ [链路配置] ──→ [文件上传]
       │                │
       ↓                ↓
[权限配置]          [关联查询文档配置]
```
