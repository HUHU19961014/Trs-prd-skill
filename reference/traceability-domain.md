# 追溯领域模板

## 1. 追溯谱系（Lot Genealogy）

### 关键概念
- **拆分**：一个批次拆分为多个子批次
- **合并**：多个批次合并为一个批次
- **转产**：物料从一个工单转移到另一个工单
- **返工**：不合格品返回重新加工
- **报废**：批次作废处理

### 多对多关系
- 父子关系记录
- 时间戳与操作人
- 原因说明

## 2. 召回与演练（Mock Recall）

### 影响范围计算
- 上游：原料/半成品来源
- 下游：成品去向/客户
- 在制：当前生产线上的批次
- 在途：运输中的批次
- 已出货：已交付客户的批次

### 清单导出
- 库存清单
- 在制清单
- 在途清单
- 已出货清单

### 证据包
- 谱系图
- 检验报告
- 操作记录
- 时间线

## 3. 质量放行/冻结

### 状态流转
```
待检 → 检验中 → 合格/不合格 → 放行/冻结 → 解冻/报废
```

### 隔离区管理
- 物理隔离标识
- 系统状态锁定
- 解冻审批流程

## 4. 条码/标签

### 码制规则
- 一维码：Code128、EAN-13
- 二维码：QR Code、Data Matrix
- 内容格式：前缀+批次号+序列号+校验位

### 打印与贴标
- 打印模板设计
- 贴标位置规范
- 补打/作废流程

### 盘点与对账
- 定期盘点机制
- 账实差异处理
- 标签损坏处理

## 5. 审计留痕

### 记录要素
- 谁在何时（Who/When）
- 因何更改（Why）
- 改了什么（What）：前后值对比
- 如何更改（How）：操作方式

### 更正/冲销机制
- 更正申请
- 审批流程
- 冲销记录
- 原记录保留

## 6. 集成与一致性

### 主数据同步
- 物料主数据
- 客户/供应商主数据
- BOM 数据

### 事件数据流转
- 生产事件
- 质量事件
- 库存事件

### 幂等与重放
- 幂等性设计
- 消息重放机制
- 延迟与补偿策略
