### 字段明细表

```markdown
| 序号 | 字段名 | 控件类型 | 数值类型 | 长度 | 必输Y/N | 新增/编辑 | 值列表说明 | 默认值 | 校验规则 | 其他说明 |

### 字段属性说明

| 属性 | 说明 | 示例 |
|------|------|------|
| **序号** | 字段在界面上的顺序编号 | 1, 2, 3... |
| **字段名** | 界面显示的名称 | 物料类别、文件类型编码 |
| **控件类型** | 下拉框/文本/数值/日期/按钮/超链接/值列表 | 下拉框、文本 |
| **数值类型** | 字符/数值/日期 | 字符、数值 |
| **长度** | 字段最大长度 | 50、100 |
| **必输Y/N** | 是否必填 | Y、N |
| **新增/编辑** | 该字段在新增/编辑时是否可编辑 | Y/Y、N/N、Y/N |
| **值列表说明** | 下拉框取值来源，需明确取数表/快码 | 取快码Item_Categories有效值 |

| **校验规则** | 保存时的校验逻辑 | 验重、格式校验 |
| **其他说明** | 特殊逻辑说明 | 自动生成规则、模糊查询 |
```

## 5W1H 分析模板

```markdown
- **Why（为什么）**：业务背景、痛点、数据支撑
- **What（是什么）**：核心问题、影响范围
- **Who（谁）**：提出者、使用者、影响者
- **When（何时）**：使用场景、频率、期望上线
- **Where（在哪里）**：系统、设备
- **How（如何）**：解决方案、替代方案
```

## 业务背景四段式模板

```markdown
### 4.1 业务背景

**1. 业务场景**
用户在什么场景下使用这个功能？描述具体的业务流程和使用情境。

> 示例：出于业务需要，用户会将最终产品的销售、物流、生产、采购等多流程文件上传到系统中进行线上管理...

**2. 行业特点**
本行业/本企业有什么特殊之处？涉及哪些专业领域或特殊要求？

> 示例：硅材供应链主要包含组件、电池、硅片、硅棒、多晶硅、硅粉、工业硅、硅矿八大工段。包含外协、代工、直采等多种不同场景...

**3. 当前痛点**
现在存在什么问题？没有这个功能时用户怎么做的？有什么困难？

> 示例：不同场景对应的文件及数据串联关系均有不同，甚至同样工段根据代工客户不同也可能产生区别...

**4. 解决方向**
本功能如何解决这些问题？预期达到什么效果？

> 示例：需要功能支持按不同供应链场景灵活配置链路，包括需要勾稽哪些文件、不同文件间的勾稽关系...
```

## 补充逻辑说明模板

```markdown
### 补充逻辑

**1. 查询逻辑**
- 查询条件非必填项，查询条件置空进行查询时展示系统内全量数据
- 查询结果按XXX编码升序展示
- 支持模糊查询的字段：XXX、XXX

**2. 删除校验逻辑**
- 删除前进行检查，检查当前数据在XXX功能中是否被引用
- 若已被引用，则报错不允许删除，报错消息参考："当前数据已被使用，不允许删除，请失效当前数据或调整其他配置后删除"
- 若未被引用，则弹出确认窗口，弹窗消息参考"删除后无法恢复，是否确认删除"，由用户确认后再执行删除

**3. 自动编号逻辑**
- 保存时自动生成，生成规则为：物料类别代码+3位流水号
- 流水号从001开始递增
- 失效数据保留编码，删除数据释放编码
- 示例：物料类别为Module，已有三个文件类型，则生成编码为Module004

**4. 验重逻辑**
- 保存时校验XXX名称不允许重复
- 报错参考："当前XXX名称已存在，请重新命名"

**5. 失效逻辑（级联处理）**
- 若对XXX进行失效，同步将XXX下的XXX及XXX失效
- 失效后数据不可新增关联，但保留历史数据

**6. 权限控制**
- 功能权限：哪些角色可以操作此功能
- 数据权限：用户可以看到哪些范围的数据
```
