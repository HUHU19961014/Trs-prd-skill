## 字段设计模板

```markdown
### 字段名称：XXX

| 属性 | 值 |
|------|-----|
| 控件类型 | 文本/下拉/日期/数值/开关 |
| 必填 | 是/否 |
| 值列表来源 | 取表/快码/手工 |
| 级联关系 | 选A后B取什么 |
| 默认规则 | 单值默认带出/空 |
| 展示要求 | 显示名称/值/代码 |
| 支持搜索 | 是/否 |

**校验规则：**
- 时机：保存时/实时/关闭时
- 条件：XX字段不允许为空/格式为XXX
- 报错："[XX]不能为空，请填写后保存"
```

## 5W1H 分析模板

```markdown
- **Why（为什么）**：业务背景、痛点、数据支撑
- **What（是什么）**：核心问题、影响范围
- **Who（谁）**：提出者、使用者、影响者
- **When（何时）**：使用场景、频率、期望上线
- **Where（在哪里）**：系统、设备
- **How（如何）**：解决方案、替代方案
```
